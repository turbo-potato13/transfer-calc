# transfer-calc

Калькулятор издержек перевода денег по маршруту **Россия → Приднестровье → Молдова**.

Цепочка: `₽ на карте РФ → Юнистрим (комиссия 1% сверху) → ₽ наличными в кассе ПМР →
банк покупает ₽ → ПМР-рубль → банк продаёт €/лей/$`.

Две конвертации, обе в кассе, обе со спредом. На 50 000 ₽ потеря около 10% в евро — и
большая часть это **не** комиссия Юнистрима, а спреды кассы. Приложение показывает, куда
именно уходят деньги на каждом из четырёх шагов.

Это инструмент подсчёта арифметики издержек. Не инвестиционный совет.

## Статус

Приложение ещё не написано — идёт этап решений. Планирование ведётся как карта
решений: [`Docs/Wayfinder/APP_MAP.md`](Docs/Wayfinder/APP_MAP.md) плюс тикеты в
[`Docs/Wayfinder/Tickets/`](Docs/Wayfinder/Tickets/). Каждый закрытый тикет содержит
не только решение, но и разбор того, какие исходные посылки оказались неверны.

## Источник истины для формулы

[`Калькулятор перевода.xlsx`](Калькулятор%20перевода.xlsx) — проверен: разложение потери
на четыре шага сходится с прямой разницей «идеал минус факт» в ноль на всех трёх выходных
валютах. Любой расчёт в коде обязан совпадать с ним.

## Куда это едет

Статика на бесплатном Oracle Cloud: cron-скрипт раз в сутки пишет `rates.json`,
Caddy раздаёт `site/` по HTTPS. Без долгоживущего backend — на машине 1 ГБ памяти,
делится с другим сервисом. Подробности и обоснование —
[Где живёт приложение](Docs/Wayfinder/Tickets/where-the-app-lives.md).
