# transfer-calc

Калькулятор издержек обмена валюты. Показывает, сколько от суммы съедают комиссия и
курсовые спреды, и раскладывает потерю по шагам — чтобы было видно, на каком именно
шаге уходят деньги.

Считает в обе стороны: «отправил столько — получу столько» и «нужно получить столько —
отправить столько». Точка отсчёта «без потерь» — официальный курс центробанка; всё, что
до него не дошло, и есть издержки.

Любой курс можно перебить руками: опубликованный курс и курс в кассе не всегда
совпадают.

Это инструмент подсчёта арифметики. Не инвестиционный совет.

## Статус

Первая версия работает: расчёт, курсы, офлайн. Планирование продолжается.

## Как устроено

Статика, без долгоживущего backend: cron-скрипт раз в сутки собирает курсы в
`rates.json`, веб-сервер раздаёт `site/` по HTTPS. Страница читает только этот файл со
своего origin. Service worker держит калькулятор полностью работающим офлайн.
