# Набор банков-источников курса

## Question

Приложение считает только по курсам Приднестровского Сбербанка — или даёт выбрать банк?

Пользователь сказал «чаще всего это приднестровский сбер», то есть иногда не он. Вопрос в том, что делать с этим «иногда»: одного банка достаточно, потому что в остальных случаях курс всё равно вбивается руками — или выбор банка нужен как отдельная функция.

Если выбор нужен, то из кого: Юнистрим выдаёт переводы в ПМР через три банка — Приднестровский Сбербанк, Агропромбанк и Эксимбанк.

## Зачем это решает

Это разница между «одно поле курса, подставленное автоматически» и «переключатель банка, влияющий на весь расчёт». Второе заметно усложняет и экран, и логику подстановки, и его стоит брать только если ты правда ходишь в разные банки.

Есть и обратная сторона: у разных банков ПМР курсы расходятся заметно, и сравнение «где сегодня выгоднее менять» может оказаться такой же ценной функцией, как и сравнение трёх выходных валют. Но это уже расширение destination, а не его часть — решать надо осознанно.

## Что уже установлено

Проверено research-агентом 2026-09-03:

- **Приднестровский Сбербанк** — JSON API `https://api.prisbank.com/courses`, четыре группы курсов, работает.
- **Агропромбанк** — XML API `http://www.agroprombank.com/xmlinformer.php?date=ГГГГ-ММ-ДД&type=all`, документирован, кодировка windows-1251.
- **Эксимбanк** — только HTML, за антибот-заглушкой FOXCLOUD, обычный запрос получает 503. Из браузера почти наверняка недостижим.

То есть даже при положительном решении Эксимбанк, скорее всего, останется только ручным вводом — и это часть ответа, а не препятствие к нему.

Дополнено после закрытия [Доступ к курсам из браузера](browser-rate-access.md): у Прибанка `Access-Control-Allow-Origin: *`, страница читает его напрямую. У Агропромбанка CORS не проверялся — если решение окажется положительным, это первое, что нужно выяснить, потому что документированный API ещё не значит доступный из браузера.

Дополнено 2026-09-04 из сессии по [Поведение при недоступном или устаревшем курсе](stale-rate-behaviour.md): пользователь сам, без наводящего вопроса, сказал «хорошо бы сделать, чтоб можно было выбрать банк». Это сдвигает исходную посылку «одного банка достаточно» — в сессии по этому тикету начинать с того, что желание выбора уже высказано, и выяснять, в какие банки он реально ходит. Модель статуса курсов решена «по источнику» (свои `fetched_at`, `changed_at`, текст ошибки у каждого), так что второй банк ложится в неё без переделки.
