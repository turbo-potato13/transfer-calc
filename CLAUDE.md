# finance — калькулятор вывода денег Россия → Приднестровье → Молдова

## Что здесь

Личный инструмент для расчёта издержек перевода. Цепочка:

**₽ на карте РФ → Юнистрим (комиссия 1% сверху) → банк выдачи покупает ₽ → ПМР-рубли на руки → банк обмена продаёт €/лей/$**

Юнистрим выдаёт **ПМР-рубли**; наличных рублей РФ на руках не бывает. Две конвертации, обе со спредом, и **необязательно в одном банке** — забрать можно в одном, менять в другом. Банков в ПМР ровно три: Приднестровский Сбербанк, Агропромбанк, Эксимбанк. На 50 000 ₽ потеря около 10% в евро, и большая часть — не комиссия Юнистрима (1%), а спреды кассы.

## Два артефакта

- **`Калькулятор перевода.xlsx`** — готов и проверен. Источник истины для формулы: разложение потери на четыре шага сходится с прямой разницей «идеал минус факт» в ноль. Любой расчёт в коде обязан совпадать с ним.
- **`Docs/Wayfinder/APP_MAP.md`** — карта планирования приложения на телефон. Приложение ещё не написано, идёт этап решений.

## Работа по карте

Планирование ведётся скиллом **wayfinder**, который лежит в другом проекте:
`C:\unity\poezdec\.claude\skills\wayfinder\SKILL.md` — прочитать его напрямую, автоматически он здесь не подхватывается. Скилл ссылается на `/domain-modeling`, которого у пользователя нет; есть только `/grilling` (там же, в `poezdec/.claude/skills/`).

Внешнего issue-трекера нет. Трекер локальный: карта `Docs/Wayfinder/APP_MAP.md` + тикеты в `Docs/Wayfinder/Tickets/`. Раздел «Wayfinding operations» в карте описывает, как читать `status`, `claimed_by` и `blocked_by`.

**Порядок в новой сессии:**

1. Прочитать `Docs/Wayfinder/APP_MAP.md` целиком — это низкое разрешение всей карты.
2. Выбрать тикет: названный пользователем, иначе первый свободный на frontier (открыт, `claimed_by` пуст, все `blocked_by` закрыты).
3. Заполнить `claimed_by` **до** начала работы.
4. Открыть только выбранный тикет и закрытые решения, на которые он ссылается. Читать все тикеты подряд не нужно.
5. При закрытии: `## Resolution` в самом тикете, `status: closed`, одна строка в `Decisions so far` карты.

**За сессию закрывается не более одного HITL-тикета.** Research — исключение.

## Важное про эту машину

- TLS перехватывается антивирусом: `curl` к https требует `--ssl-no-revoke`, `pip install` требует `--trusted-host pypi.org --trusted-host files.pythonhosted.org`.
- LibreOffice нет, поэтому `recalc.py` из скилла `xlsx` не работает. Пересчёт и проверка xlsx — через Excel COM из PowerShell (`CalculateFullRebuild()`, затем обход `UsedRange` в поисках ячеек, чей `.Text` начинается с `#`).
- **Xlsx нельзя сохранять из Excel.** При сохранении Excel вписывает в `xl/workbook.xml` абсолютный путь к файлу вместе с именем пользователя Windows и подменяет `cp:lastModifiedBy`. Репозиторий публичный, история git необратима. Открывать только на чтение (`Workbooks.Open($path, 0, $true)`, закрывать `Close($false)`); правки текста делать заменой строк в `xl/sharedStrings.xml` при перепаковке zip. Сейчас в файле стоит `creator: openpyxl`, `lastModifiedBy: turbo-potato13` и никакого `absPath`.
- Читать xlsx можно и без Excel: `openpyxl` с `data_only=True` отдаёт закешированные значения формул. Excel нужен только чтобы **пересчитать** файл на других входах.
- В `.ps1` нельзя писать кириллицу: PowerShell 5.1 читает файл как ANSI. К листам обращаться по индексу, не по имени.

## Границы

Приложение показывает арифметику издержек. Это **не** инвестиционный инструмент, и оно не советует, что делать с деньгами.
